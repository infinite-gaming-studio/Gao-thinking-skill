# Markdown Output Template

Use this structure for the `reflection.md` file. The design follows a classical essay form — title, epigraph, opening, meditative sections, closing.

```markdown
# {{TITLE}}

*{{SUBTITLE — one line capturing the core significance}}*

{{DATE}}

---

> {{USER_ORIGINAL_WORDS — the user's sharing, quoted here}}

---

{{OPENING — 1-2 paragraphs restating the experience and the implicit question about meaning}}

---

## {{DOMAIN_A_LABEL}}

{{Reflection: connect the user's experience to this domain's significance dimension. Weave in one key concept naturally, no citations.}}

---

## {{DOMAIN_B_LABEL}}

{{Reflection: a different facet of meaning, a different light on the same experience.}}

---

## {{DOMAIN_C_LABEL}}

{{Reflection: how does this domain reveal something the others don't?}}

---

## {{DOMAIN_D_LABEL}}

{{Reflection: the contrast or complement to the previous domains.}}

---

## {{DOMAIN_E_LABEL}}

{{Reflection: the most unexpected domain — the one that opens a new angle.}}

---

> {{PULL_QUOTE — one sentence that crystallizes the core significance across all domains}}

---

{{CLOSING — return to the confider. No conclusions. Leave the final significance for them to claim.}}
```

## Design Notes

- **Separator**: Use `---` between major sections for visual breathing room
- **Blockquote**: Use `>` for the user's original words (creates distance between the person and the reflection)
- **Pull quote**: A single `> ` blockquote near the end to echo the core insight
- **Domain headers**: `##` level — thematic, not academic. Never use numbered lists.
- **Tone**: Flowing prose, not bullet points. Each domain section is a mini-essay.
- **Formatting**: Minimal — avoid bold, italics only for emphasis or foreign terms
