# Social Media Output Template

Use this template to format the significance-weaving reflection for social platforms.

## Short Version (~300 characters)

```
[One-line hook that captures the core significance]

[1-2 sentences distilling the essence]

[3-5 relevant hashtags]
```

## Long Version (~1400 characters)

```
[Title / Hook line]

[Opening — the personal experience shared]

[Paragraph 1 — significance from Domain A]
[Paragraph 2 — significance from Domain B]
[Paragraph 3 — significance from Domain C]

[Closing — return to the reader, open-ended]

[3-5 hashtags]
```

## Styling Rules

- No markdown formatting in social.txt (plain text only)
- Line breaks between paragraphs
- Hashtags: PascalCase for multi-word (#SignificanceFinding)
- Tone: reflective, not prescriptive; inviting, not concluding
- No emojis unless the user explicitly requests them
